Задание 1: Вопросы и ответы

1.1 "кот" > "код"
Ответ: true
Обоснование: так как "т"-1090 код символа выше "д"-1076

1.2 "2" + 2 * "2"
Ответ: '24'
Обоснование: сначала умножение (больше приоритет у оператора) получается 4, затем конкатенация строк

1.3 undefined == null
Ответ: true
Обоснование: один из исключений в JS

1.4 undefined != null
Ответ: false
Обоснование: undefined == null дает true, то undefined != null даст false

1.5 null == 0
Ответ: false
Обоснование: null при нестрогом сравнении равен только undefined, а с числами/строками — нет

1.6 2 > "3"
Ответ: false
Обоснование: при разных типах приводит к числу поэтому "3" => 3, а 3 > 2

1.7 null - false + true
Ответ: 1
Обоснование: null => 0 - false => 0 = 0 + true => 1 = 1. null при преобразование в число = 0

1.8 1 / "l"
Ответ: NaN
Обоснование: при приведение "l" в число будет NaN, а 1/NaN все равно будет NaN

1.9 "2" * "3"
Ответ: 6
Обоснование: "*" преобразует операнты в числа, а тут они без проблем преобразуются

1.10 4 + 5 + "O"
Ответ: '9O'
Обоснование: 4 + 5 = 9, затем конкатенация происходит, потому что второй оперант string

1.11 "l" + 4 + 5
Ответ: 'l45'
Обоснование: конкатенация строк

1.12 "4"- 2
Ответ: 2
Обоснование: "4", преобразуется в число при операторе "-"

1.13 "4"-"4x"
Ответ: NaN
Обоснование: потому что "4x" нельзя преобразовать в число

1.14 "23" == 23
Ответ: true
Обоснование: идет преобразование "23" к числу при нестрогом сравнение

1.15 null == false
Ответ: false
Обоснование: опять же прикольное исключение в js, null == undefined

1.16 "-4 "/ 0 + 1
Ответ: -Infinity
Обоснование: потому что: -4 / 0 = -Infinity + 1 = -Infinity

1.17 null + 1
Ответ: 1
Обоснование: null => 0 при преобразовании в число

1.18 undefined + null
Ответ: NaN
Обоснование: undefined => NaN

1.19 1 === "1"
Ответ: false
Обоснование: строгое сравнение по типам number и string

1.20 "2" > 10
Ответ: false
Обоснование: "2" преобразуется тут в 2, а 2 < 10

1.21 NaN == undefined
Ответ: false
Обоснование: не равен ни одному другому значению, даже самому себе

Задание 2: Console.log вопросы и ответы

2.1 console.log("5" + 3)
Ответ: '53'
Обоснование: потому что "+" со строкой преобразует число 3 в строку "3"

2.2 console.log("10"- 2)
Ответ: 8
Обоснование: потому что "-" со строкой преобразует "10" в число 10

2.3 console.log("5" * 3)
Ответ: 15
Обоснование: потому что "*" со строкой преобразует "5" в число 5

2.4 console.log("20" / 4)
Ответ: 5
Обоснование: потому что "/" со строкой преобразует "20" в число 20

2.5 console.log("17" % 5)
Ответ: 2
Обоснование: потому что "%" со строкой преобразует "17" в число 17

2.6 console.log([1, 2] + 3)
Ответ: '1,23'
Обоснование: массив преобразуется в строку и происходит конкатенация

2.7 console.log("2" ** 3)
Ответ: 8
Обоснование: потому что "**" со строкой преобразует "2" в число 2

2.8 console.log(+true)
Ответ: 1
Обоснование: явное преобразование в число true = 1

2.9 console.log(+false)
Ответ: 0
Обоснование: явное преобразование в число false = 0

2.10 console.log(null + 5)
Ответ: 5
Обоснование: null в данном случае преобразуется в число а null = 0

2.11 console.log(undefined + 5)
Ответ: NaN
Обоснование: undefined в данном случае преобразуется в число а undefined = NaN

2.12 console.log('' + 5)
Ответ: '5'
Обоснование: потому что "+" со строкой преобразует число 5 в строку "5" и происходит конкатенация

2.13 console.log('' - 5)
Ответ: -5
Обоснование: потому что "-" со строкой преобразует строку "" в число 0

2.14 console.log('' * 5)
Ответ: 0
Обоснование: потому что "*" со строкой преобразует строку "" в число 0

2.15 console.log([10] - 3)
Ответ: 7
Обоснование: потому что "-" с объектом преобразует объект [10] в число 10

2.16 console.log([1, 2] - 3)
Ответ: NaN
Обоснование: потому что "-" с объектом преобразует объект [1, 2] в строку "1,2" -> NaN

2.17 console.log({} + 1)
Ответ: '[object Object]1'
Обоснование: объект {} → строка "[object Object]"

2.18 console.log("10" + 5 - 2)
Ответ: 103
Обоснование: сначала конкатенация, затем строка "105" преобразует в число при операторе "-"

2.19 console.log("10"- 2 + 3)
Ответ: 11
Обоснование: строка "10" преобразует в число при операторе "-"
